# حالت Meshtastic برای LoRa Messenger v6

این نسخه یک **حالت سازگاری با Meshtastic** به پروژهٔ شما اضافه می‌کند. وقتی روشنش کنید، دستگاه شما همان پروتکل رادیویی واقعی Meshtastic را حرف می‌زند و در شبکهٔ Meshtastic مثل یک نود معمولی دیده می‌شود (بدون نیاز به فلش‌کردن فریم‌ور Meshtastic).

## فایل‌ها (هر چهار فایل باید کنار هم در پوشهٔ `lora_messenger_v6` باشند)
| فایل | کار |
|---|---|
| `lora_messenger_v6.ino` | برنامهٔ اصلی (تغییر داده شده) |
| `assets.h` | رابط وب (کارت جدید Meshtastic در Settings) |
| `mt_core.h` | **جدید** – هستهٔ پروتکل Meshtastic (هدر، AES-CTR، protobuf، پریست‌ها) |
| `meshtastic.h` | **جدید** – اتصال به پیام‌ها/مخاطبین/رادیوی پروژهٔ شما |

نیاز به کتابخانهٔ اضافه ندارد (از mbedtls خودِ ESP32 استفاده می‌شود).

## روش استفاده
1. کد را فلش کنید و وارد **Settings ← Meshtastic** شوید.
2. اگر شبکه‌تان کانال خصوصی دارد: لینک اشتراک‌گذاری کانال (`https://meshtastic.org/e/#...`) را بچسبانید و Apply بزنید؛ نام، کلید، پریست و hop همه با هم تنظیم می‌شوند. وگرنه همان کانال پیش‌فرض (LongFast + کلید عمومی) فعال است.
3. سوییچ **Meshtastic mode** را روشن و تأیید کنید.
4. نودهای Meshtastic باید روی ناحیهٔ **EU_433** و همان پریست/نام کانال/کلید باشند.

## چه چیزهایی کار می‌کند
- ارسال/دریافت پیام متنی (کانال عمومی و پیام خصوصی به یک نود)، Reply
- پیام خصوصی با ACK و ارسال مجدد (۱ بار اصلی + ۳ تلاش مجدد، مثل Meshtastic)
- شناسایی نودها (NodeInfo) با نام واقعی، موقعیت نودها (رادار/فاصله/جهت)
- اشتراک موقعیت خودتان (در حالت Live فقط دقیقه‌ای یک‌بار برای کم‌کردن airtime)
- Ping (از نودها می‌خواهد خودشان را معرفی کنند)، دکمهٔ SOS (متن قابل‌اطمینان + موقعیت)
- Repeater (همان سوییچ Relay): بازپخش با کاهش hop و حذف تکراری‌ها
- پیام‌های سریع (Quick) به صورت متن ساده
- سقف توان ۱۰ dBm و سقف airtime ۱۰٪ در ساعت (محدودیت EU_433 خودِ Meshtastic)

## محدودیت‌ها (قابل‌توجه)
- **دو حالت همزمان نیستند.** پارامترهای رادیو متفاوت است (sync word، SF، BW، preamble)؛ در حالت Meshtastic نودهای LoRa Link شما را نمی‌شنوند و برعکس. با همان سوییچ برمی‌گردید.
- در حالت Meshtastic: ویرایش/حذف پیام، رسید خوانده‌شدن، کانال‌های خصوصی LoRa Link و تکه‌تکه‌کردن پیام بلند وجود ندارد. متن بلند تا ۳ پیام جدا (هرکدام ≤ ۲۰۰ بایت) ارسال می‌شود.
- پیام خصوصی PKI (کلید عمومی نود، Meshtastic 2.5+) پیاده نشده؛ DM با کلید کانال رمز می‌شود. نودها همچنان آن را روی همان کانال می‌خوانند.
- ماژول‌های Meshtastic مثل MQTT، تلمتری، Store&Forward و پیکربندی ریموت پیاده نشده‌اند.
- تعداد مخاطبین همان ۸ تای قبلی است؛ در شبکهٔ شلوغ قدیمی‌ترین نود جایگزین می‌شود.
- توان ۱۰ dBm فقط برای حالت Meshtastic اعمال می‌شود (`MT_MAX_TX_DBM` در `mt_core.h`)؛ قوانین محلی بر عهدهٔ شماست.

## تست‌هایی که انجام شد
بدون سخت‌افزار، با این دو لایه:
1. هستهٔ `mt_core.h` در برابر یک پیاده‌سازی مرجع مستقل (پایتون + کتابخانهٔ رسمی protobuf مشتاستیک + AES-CTR): ۲۶ تست دوطرفه (کلید ۱ بایتی/۱۶/۳۲ بایتی/بدون رمز، هدر، هش کانال، Data/Position/User/Routing، لینک اشتراک‌گذاری).
2. اجرای **خودِ اسکچ شما** روی کامپیوتر با رادیوی مجازی: ۴۸ تست سناریو (تنظیمات رادیو، دریافت/ارسال، DM+ACK+retry، relay، SOS، ping، تغییر کانال، بازگشت به حالت قبلی).
کد روی ESP32 واقعی و رادیوی واقعی هنوز تست نشده؛ لطفاً با یک نود Meshtastic روی ۴۳۳ مگاهرتز امتحان کنید. فرکانس پیش‌فرض LongFast در EU_433 برابر 433.875 MHz است.
